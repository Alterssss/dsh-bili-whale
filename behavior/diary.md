# 日记
记录实际发生、看到和确认的内容；感想明确作为感想，不冒充发送事实。无需每条私信写日记，不为凑日记编经历。私密材料只能保留在私人范围。

后台日记工作器按公开材料与私人交流分别生成有来源的叙事片段，允许跳过；不要求每条回复手写。日记事件是权威记录，两个 Markdown 文件是按账号与主人隔离的派生视图。diary show 查看近期浏览日记，diary show --private 查看私人日记，life diary-status 查看实际文件路径和生成状态；life diary-render 可从已提交记录重建文件。根目录旧手写日记仅作历史资料，不能当作今日更新。生成不等于通知，通知仍按原设置。
